# THX Deep Note — Master v1.0

**Recreation by Aram Basmadjian (2026).**

This is the cleaned, documented and regression-tested version of the approved **Experiment F** THX Deep Note synthesizer. The most important acoustic characteristic—the delayed stereo spread between **8.0 and 12.0 seconds**—has **not** changed.

## Verified audio equivalence

The complete WAV generated by `deep_note_master.py` with its default seed/settings is **bit-for-bit identical** to the approved `deep_note_experiment_f.wav`:

- Duration: about 31.55 s; 1,514,485 stereo sample frames.
- Default output: 48,000 Hz, IEEE 32-bit floating point, stereo.
- Golden WAV SHA-256: `85dd258e69dc58b50bfda2dad2cc8ad3892a32da40aac74f3510b169871f180b`.
- Sample-data SHA-256: `6ca8b993b215025382e672a7089ab3787c3002bf4278eb7037a908fa29c8c754`.
- The golden WAV and newly rendered WAV hashes were compared and matched exactly.

The cleanup preserves numerical oscillator rendering, voice frequencies, timing, brightness, final-note pitch drift, upper-harmonic motion, gain normalization, and spatial expansion.

## Installation

Python 3.10+ recommended:

```bash
python -m pip install numpy scipy sounddevice
```

`sounddevice` is required only for playback; WAV synthesis can run without it.

## Usage

Render, save and play the approved sound:

```bash
python deep_note_master.py
```

Save without playback:

```bash
python deep_note_master.py --no-play
```

The default WAV is called `deep_note_master.wav` and is saved alongside the script. The default `OVERWRITE = True` will replace that file. Set `OVERWRITE = False` or supply `--no-overwrite` to protect existing recordings.

Other useful options:

```bash
# Use an explicitly named output (recommended when experimenting)
python deep_note_master.py --no-play --output take_2.wav

# Export as 24-bit PCM instead of 32-bit float
python deep_note_master.py --no-play --wav-format pcm24

# Turn off the slow pitch drift for A/B testing
python deep_note_master.py --no-play --wobble-cents 0

# Turn off the independent harmonic evolution
python deep_note_master.py --no-play --harmonic-motion-db 0

# Compare with the older, linear stereo spread
python deep_note_master.py --no-play --stereo-spread-mode linear

# Try different lead voice pitch/timing *without changing globals*
python deep_note_master.py --no-play --lead-hz 280 --lead-delay 0.5
```

## Settings not to change inadvertently

These controls reproduce the approved transition:

```python
STEREO_SPREAD_MODE  = "bloom"
STEREO_SPREAD_START = 8.0
STEREO_SPREAD_END   = 12.0
EARLY_PAN_START    = -0.70
EARLY_PAN_PEAK     = 0.65
SOLO_WANDER        = 0.55
LEAD_DIVE_POWER    = 1.8
CRESC_START        = 11.7
```

## Cleanup performed

1. Updated the module overview to document the four phases and the separation of global auto-pan from individual voice spread.
2. Clarified comments on pitch drift, slowly evolving harmonic amplitudes, the special lead voice, and export formats.
3. Kept numeric synthesis calculations and their order unchanged.
4. Added a check that chord-ratio and chord-count tables have matching lengths, along with validity checks for their values.
5. Added bounds checks for pan controls so accidental out-of-range settings fail clearly instead of being silently clipped.
6. Reworked the lead frequency and lead-onset CLI overrides to be **local to a render**, so one call cannot silently affect subsequent renders.
7. Preserved the safe, atomic overwrite behavior, WAV formats, and the old stereo mode for A/B tests.
8. Added dedicated quick regression tests and a full 48 kHz golden-master sample comparison.
9. Renamed the default output file to avoid overwriting the earlier approved Experiment F WAV.

## Regression tests

Quick tests (reduced sample rate for fast feedback):

```bash
python -m unittest -v test_deep_note_master.py
```

Full sample-by-sample 48 kHz verification against the approved master:

**macOS/Linux:**

```bash
DEEP_NOTE_FULL_TEST=1 python -m unittest -v test_deep_note_master.py
```

**Windows PowerShell:**

```powershell
$env:DEEP_NOTE_FULL_TEST = '1'
python -m unittest -v test_deep_note_master.py
```

Keep the two original Experiment F files alongside the cleaned script when running the regression suite. Running the synthesizer itself does not need them.

**Result:** All 10 regression tests passed, including the full 48 kHz master comparison; zero sample differences were detected.

## Future changes

Keep this version and WAV as a baseline. For any future sound-design changes, use a different filename and random seed held constant between comparisons. If a code-only change is intended, require exact float32 sample equivalence to the master, as done here.
